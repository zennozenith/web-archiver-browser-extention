URL Archiver – Preferences

Server

Receives a JSON POST for every capture. Used for both the archive endpoint and the pending list.

Pending list

A GET returning a JSON array of URL strings or objects {"id", "url", "title"} (also accepts {"items": [...]}). Leave empty to disable.

What to capture

Comma-separated. Values are replaced with [REDACTED] in request and response headers. Comma-separated; sent with every capture.

Keyboard shortcut for quick archiving: Alt+Shift+A by default; change it under chrome://extensions/shortcuts.
