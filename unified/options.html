Server

The archive, pending and status endpoints are derived from this, e.g. …/api/archive, …/api/pending, …/api/status.
Override individual endpoints Leave a field empty to use the derived URL (shown as placeholder). Receives a multipart/form-data POST for every capture. GET returning a JSON array of URL strings or objects {"id","url","title"} (or {"items":[…]}). GET …?url=<page url> returning {"archived":true,"count":3,"versions":[{"id","archivedAt"}]}; HTTP 404 means "not archived".
Used for all endpoints.
